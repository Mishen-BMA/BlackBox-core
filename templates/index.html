What is BlackBox-Core?

BlackBox-Core is the Python backend companion to BlackBox. It handles everything that requires a server - RSA attacks, live network scanning, file forensics with proper libraries, and web vulnerability testing.

Setup

  • pip install -r requirements.txt
  • Add API keys to .env file
  • python app.py
  • Open http://127.0.0.1:5000

API Keys (optional)

  • SHODAN_API_KEY - for Shodan host lookup
  • ABUSEIPDB_API_KEY - for IP reputation
  • VIRUSTOTAL_API_KEY - for file/hash scanning
